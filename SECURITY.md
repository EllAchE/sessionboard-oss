# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting form](https://github.com/EllAchE/sessionboard-oss/security/advisories/new)
with reproduction steps, affected routes or versions, impact, and any suggested mitigation.

Do not include real credentials, session tokens, private event data, or destructive proof-of-concept
payloads. Use an isolated event and fictional identities wherever possible.

Maintainers will acknowledge a complete report, assess scope and severity, coordinate a fix, and
credit the reporter if desired. No fixed response-time or support-lifetime guarantee is currently
offered; the latest release on the default branch is the supported version.
